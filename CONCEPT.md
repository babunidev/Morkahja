# Morkahja — concept

**Author:** Babuni.dev

Morkahja is a browser-based RPG in a personally developed fantasy world. The repository's client, server and shared code indicate a persistent player experience with character avatars, encounters, inventory, achievements, expansions and social features. Its UI and encounter content are linked to original game-design and worldbuilding work.

This is a reconstruction from committed project code and README, not a complete statement of the world's canon or the historic first concept. The separate Ethera repository develops another chapter in the Morkahja world.
